# 🎥 YouTube Homepage Clone

A responsive clone of the YouTube homepage built using **HTML5** and **CSS3** as part of my frontend development learning journey.

The project recreates the layout of YouTube's homepage, focusing on modern CSS layout techniques like Flexbox and CSS Grid while following clean code organization.

## ✨ Features

- Responsive video grid
- Fixed navigation header
- Sidebar navigation
- Search bar with styled placeholder
- Search and voice search buttons
- Hover tooltips
- Notification badge
- Clickable video thumbnails
- Clickable video titles
- YouTube-inspired UI
- Organized CSS into separate files

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Google Fonts (Roboto)
